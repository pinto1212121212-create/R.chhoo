# הנה"ח — אוריאל פינטו

אפליקציית הנהלת חשבונות לעוסק פטור: תיעוד הכנסות והוצאות, שמירת קבלות,
אומדן מס, צ'קליסט מסמכים לדוח השנתי, והפקת חבילה מלאה לרו"ח.

עובדת כולה בדפדפן, ללא שרת. הנתונים נשמרים במכשיר.

## הפעלה

```bash
# כל שרת סטטי מספיק
python3 -m http.server 8000
```

ואז `http://localhost:8000`. אין שלב build.

> פתיחה ישירה של הקובץ (`file://`) לא תעבוד — IndexedDB דורש origin אמיתי.

מומלץ להוסיף את האתר למסך הבית בטלפון: זה משפר את הסיכוי שהדפדפן ישמור על
האחסון לאורך זמן.

## בדיקות

```bash
npm install
npm test
```

בדיקות מקצה לקצה בדפדפן אמיתי (Playwright): הזנת רשומות, שמירה, **הישרדות
רענון**, סינון לפי שנה, שמירת קבלה כ-Blob, ומחזור גיבוי-ושחזור מלא לתוך
פרופיל ריק.

הבדיקה המרכזית היא "הנתונים שרדו רענון". הבאג שהשבית את האפליקציה — קריאה
ל-API אחסון שלא קיים — עבר בדיקת תחביר בלי בעיה; רק הרצה אמיתית תופסת אותו.

אם הדפדפן כבר מותקן במערכת: `CHROME_PATH=/path/to/chrome npm test`.

## מבנה

```
index.html                 האפליקציה כולה — HTML, CSS ו-JS בקובץ אחד
icon.png                   אייקון למסך הבית
vendor/                    xlsx ו-jszip, מאוחסנים מקומית
worker/                    שרת ביניים אופציונלי לסריקת קבלות עם Claude
test/e2e.mjs               בדיקות דפדפן
```

הקובץ היחיד הוא בחירה מכוונת: אין תלויות, אין build, והעלאה לאחסון סטטי היא
העתקת קובץ. `vendor/` מקומי כדי שהאפליקציה תעבוד גם אופליין וגם אם ה-CDN
נחסם — וכדי להסיר סיכון שרשרת אספקה.

## אחסון

הכל נשמר ב-**IndexedDB** בדפדפן, בשלושה object stores:

| Store | תוכן |
|---|---|
| `entries` | הכנסות והוצאות. אינדקסים לפי `date` ו-`type` |
| `files` | קבלות, טפסים ומסמכים — כ-Blob |
| `meta` | הגדרות, צ'קליסט המסמכים, סטטוס שנים |

הסכימה מנוהלת בגרסאות (`DB_VERSION`) עם נקודת מיגרציה ב-`openDB()`, כדי
שאפשר יהיה לשנות מבנה בעתיד בלי לאבד נתונים.

האפליקציה מבקשת `navigator.storage.persist()` כדי שהדפדפן לא ימחק את
האחסון אוטומטית.

### גיבוי — לא אופציונלי

הנתונים קיימים במכשיר אחד בלבד. טלפון שאבד, פורמט, או "נקה נתוני גלישה"
מוחקים הכל, ורשומות מס צריכות לשרוד שבע שנים.

בטאב **סיכום** יש **"גבה הכל לקובץ ZIP"** — קובץ אחד עם כל הרשומות, הקבלות,
הטפסים וההגדרות, שאפשר לשמור בדרייב או לשלוח לעצמך במייל. **"שחזר מגיבוי"**
מחזיר את הכל, גם במכשיר אחר. האפליקציה מתריעה אם לא גובה מעל 30 יום.

## נתוני מס

כל שיעורי המס יושבים ב-`TAX_YEARS` בראש ה-script, בלוק אחד לכל שנה: מדרגות,
שווי נקודת זיכוי, תקרת עוסק פטור, ושיעורי ביטוח לאומי.

שנה שאין לה בלוק מחושבת לפי השנה המוגדרת הקרובה שקדמה לה, והאפליקציה מציגה
על כך אזהרה גלויה.

**כל השיעורים מסומנים כרגע `verified: false`** — הם הועתקו מהמימוש הקודם ולא
נבדקו מול הפרסום הרשמי. לפני הסתמכות: ודא מול רשות המסים וביטוח לאומי,
ואז סמן `verified: true`.

האומדן הוא אומדן. הוא לא מכיר בניכויי פנסיה וקרן השתלמות, ולא בנקודות זיכוי
מעבר למה שהוזן ידנית. המספר הסופי נקבע אצל הרו"ח.

## סריקת קבלות עם AI

כבויה כברירת מחדל. היא דורשת שרת ביניים שמחזיק את מפתח ה-API — אסור להטמיע
מפתח בדף ציבורי. ראה `worker/README.md`, ואז מלא ב-`index.html`:

```js
const AI_ENDPOINT = 'https://hanhac-scan.<שם>.workers.dev';
```

## פרטיות

הדף מכיל שם מלא ופרטי משפחה, והנתונים כוללים מסמכי מס. יש `noindex` שמונע
הופעה במנועי חיפוש, אבל **כל מי שיש לו את הכתובת יכול לפתוח את הדף** — אם הוא
מתארח באחסון ציבורי. הנתונים עצמם לעולם לא עוזבים את המכשיר: הם לא נשלחים
לשום שרת, גם לא לגיבוי. הגיבוי הוא קובץ שיורד אליך.
